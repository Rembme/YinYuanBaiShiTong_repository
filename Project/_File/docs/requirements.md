# 产品需求说明

## 1. 产品目标

建设“印苑百事通”，为北京印刷学院师生提供校园通知与教学管理制度的统一检索入口。系统采用自然语言查询，尽可能返回可核对的原文链接或 PDF 页码，并支持按通知专区订阅和生成个人周报。

## 2. 用户与权限

### 学生

- 注册/登录（首版本地账号方案；生产接入学校统一认证需另行确认）。
- 搜索通知与制度，阅读来源和发布时间。
- 创建、切换、删除本人会话；会话上下文最多保留最近 20 轮。
- 订阅或取消订阅通知专区。
- 查看本人周报；只有用户填写邮箱并主动同意、且服务已配置后，才接收邮件。

### 管理员

- 管理数据来源、专区映射和采集任务。
- 导入知识 PDF，查看处理状态和采集错误。
- 管理用户状态和管理员权限。
- 查看周报生成和邮件投递状态。

## 3. 内容范围

### 官方网站来源

- 信息工程学院：`https://mie.bigc.edu.cn/`
- 北京印刷学院官网：`https://www.bigc.edu.cn/index.htm`
- 北京印刷学院新闻网：`https://news.bigc.edu.cn/`
- 其他经确认的学校官方网页。

初始专区建议映射为以上三类来源与“其他官方网页”。所有来源只能由管理员配置在允许域名列表内。来源和专区名称在上线前由项目方确认。

### 制度知识库

初始 PDF 为 `data/knowledge/knowledge_base.pdf`。目录主题包括教师教学、教学质量、教务、学务、实践教学和教材管理等。导入时保留文件名、页码、章节、条款和可提取的日期/版本信息。年份计划、旧版规定需要提示版本，不得将其无依据地描述为当前有效政策。

## 4. 功能需求

### 4.1 检索与问答

- 支持中文自然语言查询、关键词和语义检索。
- 根据问题时效性，在实时通知与制度知识库之间分流；无法判断时组合查询并分开标注来源。
- 回答附通知原文链接或 PDF 页码/条款。
- 检索不到依据时说明未找到，不能编造内容。
- 支持 SSE 增量输出、连接断开处理和错误提示。

### 4.2 会话

- 会话属于单一用户，默认最多携带最近 20 轮上下文。
- 支持列表、创建、切换和删除。
- 保存用户与助手消息及引用来源。

### 4.3 个性化订阅

- 支持查看专区、订阅、取消订阅。
- 支持从对话中识别自然语言订阅意图；不能确定专区时先要求确认。
- 周报及推送只包含用户订阅专区中的通知。

### 4.4 周报

- 定时聚合上一周期的新通知，按专区组织。
- 包含标题、摘要、发布日期和原文链接。
- 站内可查看；配置 SMTP 与用户邮箱后可邮件推送。
- 生成和投递状态可追踪，可处理重试与无新内容情况。

### 4.5 采集与管理

- 管理员可管理来源、手动触发采集、查看任务结果。
- 定时增量采集；限制允许域名、最大页数、超时、访问频率和重试。
- 记录原文 URL、标题、正文、发布时间、专区、采集时间、内容哈希和状态。
- 对重复、更新、撤下与解析失败内容进行记录。

### 4.6 身份与安全

- 学生和管理员角色分离；后端逐接口授权。
- 学生只能访问本人会话、订阅和周报。
- 密码采用强哈希保存；JWT 设置有效期；模型 key、SMTP 密码不进源码、日志或前端。
- 生产启用 HTTPS、限流、输入校验、备份及管理员凭据轮换。

## 5. 非功能要求

- 架构可维护，功能按模块分层，数据库由迁移脚本管理。
- 页面支持桌面和手机尺寸，提供空状态、加载和故障提示。
- 通知、PDF 片段和回答引用具备可追溯来源。
- 爬虫、模型与邮件失败可观察并可重试。
- 所有时间统一存储为 UTC，面向师生展示采用 `Asia/Shanghai`。

## 6. 首版验收口径

- 能从配置的网站采集通知并保留来源与发布时间。
- 能导入 PDF，并从制度查询返回正确片段、页码及版本信息。
- 实时通知查询与制度查询按意图路由，回答提供来源。
- 用户间会话、订阅和周报数据隔离。
- SSE 可逐步输出，连接中止后可清理资源。
- 订阅影响周报内容；邮件未配置时不阻塞站内周报。
- 管理接口对学生拒绝访问；项目不提交真实密钥。
